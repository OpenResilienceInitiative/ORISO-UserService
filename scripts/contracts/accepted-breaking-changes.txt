# Breaking changes that were made on purpose.
#
# verify-provider-source-compatibility.sh passes this file to oasdiff as
# --err-ignore and --warn-ignore. oasdiff skips a change when one line holds
# its method, its path and its full message (case-insensitive). Other lines,
# such as these comments, match nothing.
#
# Reviewers confirm every entry in the pull request that adds it.
# An entry can be deleted once the change has reached every long-lived branch.

# ADR-032 / ORISO-UserService#1650: the cal.com notification lookup is removed.
GET /users/notifications api path removed without deprecation
# ADR-032 / ORISO-UserService#1650: the cal.com feature flag is no longer sent.
GET /users/data removed the optional property `appointmentFeatureEnabled` from the response with the `200` status

# ORISO-Frontend#2287: advice seekers' appointment requests (REQUESTED) and declined requests
# (DECLINED). The only consumer, ORISO-Frontend, reads both since #2298 and merges after this.
GET /users/appointments/upcoming added the new `DECLINED` enum value to the `items/status` response property for the response status `200`
GET /users/appointments/upcoming added the new `REQUESTED` enum value to the `items/status` response property for the response status `200`
GET /users/sessions/{sessionId}/appointments added the new `DECLINED` enum value to the `items/status` response property for the response status `200`
GET /users/sessions/{sessionId}/appointments added the new `REQUESTED` enum value to the `items/status` response property for the response status `200`
POST /users/sessions/{sessionId}/appointments added the new `DECLINED` enum value to the `status` response property for the response status `201`
POST /users/sessions/{sessionId}/appointments added the new `REQUESTED` enum value to the `status` response property for the response status `201`
PUT /users/sessions/{sessionId}/appointments/{appointmentId} added the new `DECLINED` enum value to the `status` response property for the response status `200`
PUT /users/sessions/{sessionId}/appointments/{appointmentId} added the new `REQUESTED` enum value to the `status` response property for the response status `200`
POST /users/sessions/{sessionId}/appointments/{appointmentId}/cancel added the new `DECLINED` enum value to the `status` response property for the response status `200`
POST /users/sessions/{sessionId}/appointments/{appointmentId}/cancel added the new `REQUESTED` enum value to the `status` response property for the response status `200`
