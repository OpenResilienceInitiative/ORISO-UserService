# Breaking changes that were made on purpose.
#
# verify-provider-source-compatibility.sh passes this file to oasdiff as
# --err-ignore and --warn-ignore. oasdiff skips a change when one line holds
# its method, its path and its full message (case-insensitive). Other lines,
# such as these comments, match nothing.
#
# Reviewers confirm every entry in the pull request that adds it.
# An entry can be deleted once the change has reached every long-lived branch.

# ADR-032 / ORISO-UserService#1650: the cal.com notification lookup is removed.
GET /users/notifications api path removed without deprecation
# ADR-032 / ORISO-UserService#1650: the cal.com feature flag is no longer sent.
GET /users/data removed the optional property `appointmentFeatureEnabled` from the response with the `200` status
# ORISO-Frontend#2303: the calendar shows a planned absence as entry type ABSENCE. The frontend
# reads an unknown type as "busy" and knows ABSENCE from ORISO-Frontend#2306 on.
POST /users/calendar/blockers added the new `ABSENCE` enum value to the `items/type` response property for the response status `201`
PUT /users/calendar/blockers/{blockerId} added the new `ABSENCE` enum value to the `type` response property for the response status `200`
GET /users/calendar/colleagues/{consultantId}/entries added the new `ABSENCE` enum value to the `items/type` response property for the response status `200`
GET /users/calendar/entries added the new `ABSENCE` enum value to the `items/type` response property for the response status `200`
POST /users/calendar/proposals/{proposalId}/accept added the new `ABSENCE` enum value to the `type` response property for the response status `200`
